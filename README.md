# Novel Extractor

一個把線上小說閱讀頁面轉換成 EPUB 電子書的小工具,附帶自動翻頁與 Apple Books 排版優化。

## 免責聲明

本工具僅供個人備份、離線閱讀等合法用途使用。請勿用於下載、散布受版權保護的內容,使用者需自行確保符合所在地法律及目標網站的服務條款。作者不對任何濫用行為負責。

## 需求

- Python 3.10+
- Google Chrome(已安裝在本機)

## 安裝

```bash
pip install -r requirements.txt
```

## 使用方式

1. 執行 `python app_gui.py` 開啟介面
2. 點擊「打開瀏覽器」,在跳出的瀏覽器視窗中手動登入你的帳號(登入狀態會保存在本機的 `UserData` 資料夾,下次開啟不需要重新登入)
3. 登入後,導覽到想下載小說的第一章閱讀頁,複製該頁網址
4. 把網址貼到程式的輸入框,點擊「開始從本話往後提取」
5. 程式會自動偵測「下一話」按鈕逐章翻頁擷取內容,遇到付費牆或完結標記會自動停止
6. 完成後會在程式所在目錄產生同名的 `.epub` 檔案

## 其他工具

`epub_css_fixer.py`:如果匯出的 EPUB 在 Apple Books 排版跑掉(圖片撐版、字體鎖死等),可用這個腳本重新套用一套標準 CSS 並重新打包。

```bash
python epub_css_fixer.py 輸入檔.epub [輸出檔.epub]
```

## 注意事項

- `UserData` 資料夾內含你的瀏覽器登入狀態(cookie),請勿上傳分享,已加入 `.gitignore`
- 目標網站有反爬蟲防護時,擷取過程可能需要手動處理驗證
